# OTR - Modern Business Website

A professional, responsive business website built with HTML5, CSS3, and JavaScript.

## Features

✨ **Modern Design**
- Clean and professional layout
- Responsive design that works on all devices
- Smooth animations and transitions
- Beautiful gradient hero section

📱 **Mobile Friendly**
- Hamburger menu for mobile navigation
- Responsive grid layouts
- Touch-friendly buttons and links

🎨 **Sections Included**
- Hero section with call-to-action
- Services showcase with 4 service cards
- About section with company statistics
- Contact form with validation
- Footer with social media links

🚀 **Interactive Features**
- Smooth scroll navigation
- Mobile menu toggle
- Form submission handling
- Scroll animations for elements
- Hover effects on cards and buttons

## File Structure

```
otr/
├── index.html      # Main HTML file
├── styles.css      # Stylesheet with responsive design
├── script.js       # JavaScript for interactivity
└── README.md       # This file
```

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. No additional dependencies required!

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #007bff;
    --secondary-color: #0056b3;
    --dark-color: #1a1a1a;
    --light-color: #f8f9fa;
}
```

### Content
Edit the text and images in `index.html` to match your business.

### Services
Modify the service cards in the Services section to showcase your offerings.
